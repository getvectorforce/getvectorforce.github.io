SECTION 01 // ARCHITECTURE

Eliminate context drift across agents.

Model claims are never confused with verifiable workspace evidence. Every handoff is deterministic and auditable.

01 // LOCAL-FIRST

Zero runtime dependencies

Runs strictly on Node.js built-ins and local SQLite WAL. No background bloat, works offline, and keeps secrets out of receipts.

02 // MCP PROTOCOL

11 native agent tools

Auto-configured per IDE. Coding agents list active tasks, check workspace drift, reason over memory, and commit checkpoints.

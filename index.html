Core Capabilities

Engineered for Privacy, Speed & Verifiability

Built from the ground up using pure Node.js built-ins (node:sqlite, node:crypto, node:http) with zero third-party runtime dependencies.

🔒

Claims vs. Evidence Fencing

Model assertions (goals, constraints, ADRs) are recorded as claims. Git commit SHAs and SHA-256 document hashes are recorded as evidence—preventing AI hallucinations from masquerading as ground truth.

🧭

Workspace & Document Drift

Automatically detects if a commit changed or an allowlisted specification drifted since the last checkpoint, alerting your agent before it writes conflicting code.

🧠

Meta Muse & Llama Reasoning

Run vf reason to synthesize where you left off, what changed in the codebase, architectural risks, and ranked next steps—with graceful offline fallback.

🔌

Universal MCP Protocol

Exposes a compliant JSON-RPC stdio Model Context Protocol server with 9 specialized tools for Google Antigravity, Command Code, Meta Muse, and OpenAI Codex.

📦

Tamper-Evident Handoffs

Export selective context packages with SHA-256 manifest verification. Share task continuity with teammates or remote workspaces without leaking secrets.

🛡️

Zero-Leak Allowlist Policy

Strict workspace containment blocks path traversal (..), symlinks, binary files, and sensitive credentials (.env, *.key). Receipts never store raw file bodies.

Step-by-Step Setup

Installation & Quickstart Guide

Get VectorForce running in under 60 seconds. Requires Node.js 22.5.0+ (uses native built-in node:sqlite with zero external dependencies).

Setup Checklist

  • 1 Install VectorForce
  • 2 Initialize & Create Task
  • 3 Connect AI Harnesses
  • 4 Commit Checkpoints
  • 5 AI Memory & Studio UI
STEP 1

Install VectorForce (npm or GitHub)

Install globally via npm to use the vf and vectorforce CLI commands anywhere, or clone directly from GitHub:

Terminal — Global npm Install or Source Clone 
# Option A: Install globally from npm (Recommended)
npm install -g vectorforce

# Option B: Run directly via npx without installing
npx vectorforce --help

# Option C: Clone from GitHub (Zero dependencies to install!)
git clone https://github.com/getvectorforce/VectorForce.git
cd VectorForce && npm test
STEP 2

Initialize Your Project & Create an Active Task

Navigate to your repository and initialize VectorForce. This creates a local, git-ignored .vectorforce/vectorforce.db SQLite WAL store inside your workspace.

Terminal — Project & Task Initialization 
# 1. Initialize VectorForce in your repository root
vf init

# 2. Create and activate an engineering task
vf task auth-module "Implement PKCE OAuth Authentication"

# 3. Allowlist architecture documents for cryptographic hash tracking
vf policy allow AGENTS.md
vf policy allow README.md
STEP 3

Connect Your AI Coding Agent (Zero Manual JSON Editing)

How MCP actually works: You never have to run vf mcp manually in a terminal! Instead, each AI coding tool reads its own configuration file and automatically spawns VectorForce in the background over stdio.

⚡
Google Antigravity: Reads .agents/mcp_config.json (workspace) and ~/.gemini/antigravity/mcp_config.json (global IDE).
⌘
Claude Code & Command Code: Automatically detect and read .mcp.json in your project root (or via claude mcp add / cmd mcp add).
🦙
Meta Muse: Reads ~/.config/muse/settings.json and workspace .muse/mcp_config.json.
◈
OpenAI Codex CLI: Reads .codex/config.toml and ~/.codex/config.toml.
Auto-Configure All Harnesses + Verify with vf status 
# 1. Auto-configure Antigravity, Claude Code, Command Code, Meta Muse & Codex:
npx vectorforce config install all

# 2. Check which MCP config files were created and verify readiness:
npx vectorforce status

# Note: You do NOT need to run "vf mcp" manually!
# Each AI tool reads its config file below and spawns the MCP server automatically.
✅ How do I know it's working inside my AI agent?
Open your AI coding agent (Antigravity, Claude Code, Command Code, Muse, or Codex) and type in the chat:
"List active VectorForce tasks and check workspace drift"
You will immediately see the agent call the list_tasks and check_workspace_drift MCP tools!
STEP 4

Capture Checkpoints & Detect Workspace Drift

At the end of a work session—or before switching from one AI agent to another—record an immutable checkpoint. When resuming, check for drift and retrieve the authorized briefing:

Terminal — Checkpoint, Drift & Cross-Harness Resume 
# Commit an immutable checkpoint with Claims + Verifiable Evidence
vf checkpoint --task auth-module \
  --summary "Completed PKCE OAuth handshake and token validation" \
  --goal "Ship secure OAuth flow" \
  --constraint "Zero external auth libraries" \
  --decision "DEC-AUTH-01:PKCE:Use SHA-256 code challenge with local storage" \
  --next "Implement refresh token rotation" \
  --doc "AGENTS.md"

# Check if Git commits or allowlisted files drifted since the checkpoint
vf drift --task auth-module

# Generate an authorized briefing for your destination harness
vf resume --task auth-module --dest antigravity
STEP 5

Configure AI Memory Models (Meta Muse & Muse Spark Open 1st Priority + Fireworks, Ollama, OpenRouter, OpenAI, Anthropic, BYOK)

Built for the Meta Muse Hackathon: VectorForce makes Meta Muse (muse-spark-1.3) and the open-weights Meta Muse Spark Open (muse-spark-open • 1M token context window) its #1 priority reasoning models—accessible directly via Meta API, Fireworks AI, OpenRouter, or Local Ollama:

Meta Muse Direct API + Open-Source Muse Spark Open (1st Priority Default) 
# Option A: Configure Meta Muse Direct API (api.meta.ai/v1 • muse-spark-1.3)
vf config muse <YOUR_API_KEY>
vf reason --task auth-module

# Option B: Use Open-Weights "Muse Spark Open" (1M Context) via Fireworks AI:
vf config fireworks <YOUR_FIREWORKS_API_KEY> accounts/fireworks/models/muse-spark-open
vf reason --task auth-module

# Option C: Use "Muse Spark Open" via OpenRouter:
vf config openrouter <YOUR_OPENROUTER_API_KEY> meta/muse-spark-open

# Launch VectorForce Studio Web Control Center on http://127.0.0.1:3210
vf studio
🖥️ Configure Visually in VectorForce Studio: Run vf studio (opens http://127.0.0.1:3210) and click the Settings tab in the sidebar to switch between Meta Muse, Fireworks AI (muse-spark-open), OpenRouter, Ollama, OpenAI, or Anthropic. Need deterministic output with zero LLM calls? Run vf reason --task auth-module --raw.
Model Context Protocol

9 Native MCP Tools for Autonomous Agents

Once connected via MCP, your AI coding agent automatically calls these tools to stay aligned with your project's architectural invariants.

save_checkpoint WRITE

Commits an immutable checkpoint combining model claims with verifiable Git commit SHAs and allowlisted document hashes.

get_resume_briefing READ

Retrieves a harness-authorized markdown briefing separating invariant constraints, active goals, and verified evidence.

check_workspace_drift VERIFY

Compares the live working tree and allowlisted files against the latest checkpoint to flag silent changes.

reason_about_task AI MEMORY

Generates a Llama / Meta Muse narrative summarizing where work left off, architectural risks, and ranked next actions.

list_tasks QUERY

Discovers and filters active, paused, or completed tasks tracked inside the workspace SQLite WAL database.

set_document_policy POLICY

Manages the strict project allowlist governing which markdown or architecture files can be collected as evidence.

export_handoff BUNDLE

Packages selected checkpoints and verified evidence into a tamper-evident SHA-256 bundle with preview mode.

import_handoff RECONCILE

Cryptographically verifies a handoff manifest and safely imports external task context into a destination workspace.

get_timeline AUDIT

Synthesizes a chronological continuity recap of checkpoints, decisions, and handoffs across sessions.
